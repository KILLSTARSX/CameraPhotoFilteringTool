                相机照片筛选工具  使用说明书
                （版本 v3.3 · 作者：KILL-STAR SX）
════════════════════════════════════════════════════════════

【软件简介】
本工具用于整理数码相机拍摄的照片：相机通常设置为"JPG + RAW 双格式"拍摄，
同一张照片会同时生成一个 JPG 文件和一个 RAW 文件。经过挑选、删除后，文件夹
里常常残留"只有 JPG 没有 RAW"或"只有 RAW 没有 JPG"的孤立文件。本工具可以
自动找出这些孤立文件，并在您确认后把它们移入 Windows 回收站（可恢复，
绝不永久删除）。

【运行环境】
- Windows 10 / 11。
- 打包好的 exe 版本无需安装任何软件，双击即可运行。
- 源码版本需要 Python 3.10 及以上，并安装 Pillow、send2trash。

【界面说明】
1. 目标文件夹：输入框 + "浏览…"按钮。点击"浏览…"选择文件夹后会【自动开始
   扫描】，无需再点扫描按钮。
2. RAW 格式：下拉选择（标签为"相机品牌"）
   - 自动识别（默认）：程序自动探测文件夹内实际存在的 RAW 格式并参与配对，
     无需关心相机品牌。扫描完成后，相机品牌下拉框保持显示"自动识别"且
     【可直接操作】——直接在下拉框选择品牌即切换为手动模式（无需锁定、
     无需额外按钮），识别到的后缀显示在"后缀"输入框内（如 .rw2）；
   - 各相机品牌（松下/佳能/尼康/索尼/富士/奥林巴斯/宾得/适马/三星/理光/
     徕卡/哈苏/飞思/玛米亚/利图）：自动填入对应 RAW 后缀；
   - 自定义：在"后缀"输入框手动输入一个或多个后缀，逗号分隔，
     例如：.rw2,.dng 。扩展名不区分大小写。
   重要保护：如果您手动选择的品牌与实际格式不符（例如选了索尼 .ARW，文件夹
   里其实是 .RW2），状态栏会提示"检测到文件夹内 RAW 格式为 .RW2，与所选
   格式不符，建议切换为自动识别或选择正确品牌"，并且这些不匹配的 RAW 文件
   不会被列为孤立文件，防止误删。
3. 扫描范围：下拉选择
   - 仅当前文件夹（默认）：只扫描所选文件夹第一级；
   - 包含一级子文件夹 / 包含二级子文件夹 / 包含所有子文件夹。
   递归扫描时所有层级的文件按基础名配对（路径不参与判断），删除时保留文件
   原始位置。
4. 删除方式（三选一）：只删除孤立的 JPG 文件 / 只删除孤立的 RAW 文件 /
   删除全部孤立文件。
5. 文件列表：显示所有孤立文件的 文件名 / 类型（JPG、RAW）/ 文件大小 /
   所在文件夹。
   - 【单击排序】单击"文件名"、"类型"或"文件大小"表头即可按该列排序，
     再次单击切换升序/降序（表头显示 ▲/▼ 标记）；重新扫描后恢复默认顺序；
   - 【双击定位】双击列表中的任意文件行，会自动打开 Windows 资源管理器
     并选中（定位）该照片，方便查看原图位置。
6. 相片预览区（标题"相片预览"）：显示【将被删除的文件】，多列网格布局——
   - 一行多张，每行可显示的缩略图数量根据窗口宽度自动计算；调整窗口大小时
     排列与缩略图尺寸自动适应；
   - JPG 文件显示缩略图，保持原始宽高比缩放、不变形；
   - RAW 文件显示正方形占位框，框内居中显示大写后缀名（如 RW2、ARW）；
   - 预览区顶部有"缩略图大小"滑块，分为 小（120px）/ 中（200px，默认）/
     大（320px）三档；切换档位后程序会在后台重新生成所有缩略图，不卡界面；
   - 预览区垂直滚动（上下滚动），无左右滚动条；
   - 列表与预览区之间的分隔条可上下拖拽，调整预览区高度；
   - 点击缩略图或占位框，上方列表中对应文件会被选中并高亮。
7. "删除前二次确认"复选框：默认勾选（删除前弹出确认框，显示数量、总大小、
   回收站提示）；取消勾选后点击"确认删除"直接执行，不再弹窗。
8. "确认删除"按钮：显示待删除文件数量和总大小。当 RAW 格式未匹配
   （文件夹中没有任何已知 RAW、或检测到的格式与所选不符）时，按钮自动
   变为"强制删除"——点击后【强制】弹出二次确认（警告未匹配、确认这些
   文件不再需要 RAW 版本），即使取消了"删除前二次确认"勾选也不会跳过。
9. "操作结果"区域：显示扫描结果、跳过提示、删除成功/失败统计及失败原因。
10. "关于"按钮：自定义弹窗（显示面积大、不触发系统提示音），内容可选中
    复制，开发者链接（GitHub：https://github.com/KILLSTARSX、哔哩哔哩：
    https://space.bilibili.com/381623593）可直接点击打开；首次成功删除
    文件后固定 2 秒会自动弹出一次感谢信息，同一台设备只弹出一次。

【配置记忆】
软件会自动记住上次使用时的以下设置，下次启动自动恢复：
- 上次选择的文件夹路径；
- RAW 格式选择（自动识别 / 品牌 / 手动输入的后缀）；
- 扫描层级选择；
- "删除前二次确认"复选框的勾选状态；
- 缩略图大小档位（小/中/大）；
- 窗口大小、位置与预览区高度。
配置保存在 %APPDATA%\相机照片筛选工具\config.json（无需手工编辑）；
文件缺失或损坏时自动使用默认值。

【使用步骤】
1. 点击"浏览…"选择照片文件夹——程序自动开始扫描（状态栏显示"正在扫描..."）。
2. 需要时调整"RAW 格式"与"扫描范围"，然后点"开始扫描"重新扫描。
3. 查看文件列表与相片预览区：
   - 发现孤立文件：状态栏显示"扫描完成：发现 N 个孤立文件（JPG x 个，
     RAW y 个）"；
   - 未发现孤立文件：状态栏显示"未发现未配对文件"；
   - 格式不符：状态栏显示检测到 RAW 格式与所选不符的提示，请切换为
     "自动识别"或选择正确品牌。
4. 选择删除方式。
5. 点击"确认删除（N 个，共 X）"：
   - 勾选二次确认时：弹出确认框（文件数量、总大小、"文件将被移入回收站，
     可恢复"），点"是"继续；
   - 取消勾选时：直接开始删除。
6. 删除完成后弹出结果提示（成功/失败数量）；如有失败，"操作结果"区会列出
   失败文件名和原因。随后程序自动重新扫描当前文件夹并刷新列表和预览，
   状态栏显示"扫描完成"或"未发现未配对文件"，不会弹出多余提示框。
7. 如误删，请打开 Windows 回收站还原文件。

【配对规则说明】
- 文件名去掉扩展名后的部分称为"基础名"。
- 同一基础名同时存在至少一个 JPG 和至少一个 RAW 文件 → 已配对，不删除。
- 只有 JPG 没有 RAW → 孤立 JPG；只有 RAW 没有 JPG → 孤立 RAW。
- 比较不区分大小写：P10001.JPG 与 P10001.rw2 视为配对。
- 递归扫描时，不同子文件夹中基础名相同的文件同样参与配对；删除时按文件
  原始位置移入回收站。
- 与所选格式不符的 RAW 文件（见"界面说明"第 2 条）不参与孤立判定。

【安全说明】
- 所有删除操作均通过 send2trash 库或 Windows Shell API
  （SHFileOperation + FOF_ALLOWUNDO）实现，只会把文件移入回收站，
  程序内不存在任何永久删除调用。
- 删除过程中单个文件失败不会中断整体流程，失败原因会明确列出。

【常见问题】
1. 某些文件删除失败？
   可能原因：文件被其他程序占用、回收站已满、文件夹位于网络驱动器
   （Windows 对网络共享的回收站删除支持有限）。可稍后重试。
2. 预览区没有内容？
   当前删除方式下没有将被删除的文件时会显示提示；个别损坏的 JPG 无法解码
   时会跳过并显示数量。
3. 状态栏提示"RAW 格式与所选格式不符"？
   选择的品牌/后缀与文件夹内实际 RAW 格式不一致，切换为"自动识别"即可。
4. 为什么删除后没有弹"扫描完成"提示？
   这是 v3.0 的优化：删除完成后自动重新扫描并刷新列表和预览，结果直接显示
   在状态栏（"扫描完成"/"未发现未配对文件"），不再弹出多余提示框。
