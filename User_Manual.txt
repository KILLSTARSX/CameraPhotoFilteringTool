JPG-RAW_OrphanCleaner – User Manual
(Version v3.3 · Author: KILL-STAR SX)

【Software Overview】
This tool helps organize photos taken with digital cameras that shoot in "JPG + RAW dual format" – where each shot produces both a JPG file and a RAW file. After selecting and deleting photos, folders often end up with orphaned files – JPGs without a matching RAW, or RAW files without a matching JPG. This tool automatically finds these orphaned files and, after your confirmation, moves them to the Windows Recycle Bin (recoverable – never permanently deleted).

【System Requirements】
- Windows 10 / 11
- The packaged .exe version requires no additional software – just double-click to run
- For the source code version: Python 3.10+ with Pillow and send2trash installed

【User Interface】
1. Target Folder: Input box + "Browse…" button. Scanning starts automatically after selecting a folder.
2. RAW Format: Dropdown selection for camera brand
   - Auto-detect (default): Automatically detects RAW format in the folder
   - Brand selection: Select from 15+ camera brands, auto-fills the corresponding suffix
   - Custom: Manually enter suffixes, comma-separated (e.g. .rw2,.dng)
   - Mismatched formats trigger a warning to prevent accidental deletion
3. Scan Scope: Current folder only / Include one-level subfolders / Include two-level subfolders / Include all subfolders
4. Deletion Mode: Delete orphaned JPGs only / Delete orphaned RAW files only / Delete all orphaned files
5. File List: Displays file name, type, size, and containing folder
   - Click header to sort
   - Double-click row to locate in File Explorer
6. Photo Preview Area: Grid display of files to be deleted
   - JPG shows thumbnails, RAW shows suffix placeholder
   - Slider adjusts thumbnail size (Small/Medium/Large)
   - Click thumbnail to highlight corresponding row in list
7. Confirm Before Deletion: Checked by default. Uncheck to delete immediately.
8. Confirm Deletion: Displays file count and total size. Changes to "Force Delete" when format mismatch occurs.
9. Operation Result: Shows scan results, deletion statistics, and failure reasons.

【Configuration Memory】
The software automatically remembers these settings from your last session:
- Last selected folder path
- RAW format selection (Auto-detect / Brand / Custom suffix)
- Scan scope selection
- "Confirm before deletion" checkbox state
- Thumbnail size preset (Small/Medium/Large)
- Window size, position, and preview area height
Settings are saved to: %APPDATA%\相机照片筛选工具\config.json
If the file is missing or corrupted, defaults are used automatically.

【Usage Steps】
1. Click "Browse…" to select your photo folder – scanning starts automatically (status bar shows "Scanning...")
2. If needed, adjust RAW Format and Scan Scope, then click "Start Scan" to rescan
3. Review the file list and preview area:
   - If orphaned files are found: status bar shows "Scan complete: found N orphaned files (JPG: x, RAW: y)"
   - If no orphaned files: status bar shows "No unpaired files found"
   - If format mismatch: status bar shows the warning – switch to "Auto-detect" or choose the correct brand
4. Choose your deletion mode
5. Click "Confirm Deletion (N files, total X)":
   - With confirmation enabled: pop-up appears – click "Yes" to proceed
   - With confirmation disabled: deletion starts immediately
6. After deletion, a result pop-up shows success/failure counts. Failures are listed in the "Operation Result" area. The program then automatically rescans and refreshes – status bar shows "Scan complete" or "No unpaired files found" (no extra pop-ups)
7. If you accidentally delete something: open the Windows Recycle Bin to restore

【Pairing Rules】
- The portion of the filename without the extension is called the basename
- Same basename + at least one JPG + at least one RAW → paired – not deleted
- JPG without matching RAW → orphaned JPG
- RAW without matching JPG → orphaned RAW
- Comparison is case-insensitive: P10001.JPG and P10001.rw2 are treated as a pair
- When recursive scanning is enabled, files with the same basename in different subfolders are also paired together
- RAW files that do not match the selected format are excluded from orphan detection

【Safety Notes】
- All deletion operations use send2trash or the Windows Shell API (SHFileOperation with FOF_ALLOWUNDO)
- Files are always moved to the Recycle Bin – there is no permanent deletion in this program
- If a single file fails during deletion, the process continues for the remaining files – failure reasons are clearly listed

【Frequently Asked Questions】
1. Some files fail to delete?
   Possible reasons: the file is in use by another program, the Recycle Bin is full, or the folder is on a network drive (Windows has limited Recycle Bin support for network shares). Try again later.
2. The preview area is empty?
   It shows a message when there are no files to be deleted under the current deletion mode. Some corrupted JPGs that cannot be decoded are skipped and the count is displayed.
3. Status bar says "RAW format does not match"?
   The selected brand/suffix does not match the actual RAW files in the folder – switch to "Auto-detect" or choose the correct brand.
4. Why is there no "Scan complete" pop-up after deletion?
   This is an optimisation in v3.0: after deletion, the program automatically rescans and refreshes the list and preview – the result is shown directly in the status bar ("Scan complete" / "No unpaired files found"), with no extra pop-up.
